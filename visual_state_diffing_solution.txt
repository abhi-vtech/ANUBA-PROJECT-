================================================================================
1. THE PROBLEM WITH DWELL TIME
================================================================================

Current logic in src/temporal.py:
  "If a hand stays in zone X for more than N milliseconds -> count as pick"

This is a PROXY signal. It answers the wrong question.

Wrong question:  "Was the hand in the bin long enough?"
Right question:  "Did the ingredient actually appear on the hotdog?"

Failure modes of dwell time:
  - False positive (hover):  Hand brushes over onion bin, timer fires, counted as pick.
  - False positive (tray):   Static onion tray sits next to hotdog. bbox overlap -> counted.
  - False negative (fast):   Experienced worker grabs in <800ms. Nothing counted.
  - False negative (angle):  Hand picks from outside the ROI polygon. Zone never fires.
  - Fragile tuning:          Each ingredient needs a different number. Camera angle change
                             breaks everything. (We had onions at 2500ms, reduced, still firing.)

Root cause: the system watches the SOURCE (bin) not the OUTCOME (hotdog).


================================================================================
2. THE CORE IDEA -- VISUAL STATE DIFFING
================================================================================

In one sentence:
  Take a photo of the hotdog before the worker touches it.
  Take a photo after.
  Ask YOLO what changed.
  The difference = what was added.

Example:

  Pre-snapshot (hand not near hotdog):
    YOLO detects on hotdog area: [ hot-dog ]

  Worker applies onions and ketchup...

  Post-snapshot (hand has left hotdog area):
    YOLO detects on hotdog area: [ hot-dog, onions, ketchup_sauce ]

  DELTA = + onions, + ketchup_sauce  ->  COMMITTED TO ORDER

No hand tracking needed for commitment.
No zone polygons needed.
No dwell thresholds needed.

The YOLO model already detects all topping classes on every frame.
We re-use those exact same detections -- no new model required.


================================================================================
3. HOW IT WORKS (STEP BY STEP)
================================================================================

STEP 1 -- Pre-snapshot
  While no hand is near the hotdog, collect the set of ingredient classes
  currently visible ON the hotdog bounding box. This is the "baseline".
  Update this baseline every frame that the hotdog is clear of hands.

STEP 2 -- Active window
  When a hand enters the hotdog's bounding box (padded by 80px), freeze
  the baseline as the pre-snapshot and enter ACTIVE state.

STEP 3 -- Post-snapshot
  When the hand has been gone for 3+ consecutive frames (debounce), take
  the post-snapshot: re-check which ingredient classes are now visible ON
  the hotdog bbox.

STEP 4 -- Compute delta
  added   = post_snapshot_items - pre_snapshot_items
  removed = pre_snapshot_items  - post_snapshot_items  (logged, not used)

STEP 5 -- Commit
  For each class in "added": fire a commit event to the order state machine.

State machine per hotdog:

  +-------+  hand enters hotdog bbox   +--------+
  | CLEAN | -------------------------> | ACTIVE |
  +-------+                            +--------+
      ^                                     |
      |    hand gone for MIN_CLEAN_FRAMES   |
      +-------------------------------------+
                     |
                     v
               run delta check
               emit DiffEvent for each added class
               return to CLEAN

"""
diff_engine.py
--------------
Visual State Diffing for ingredient commit detection.

Instead of tracking hand dwell in source bins, this module compares the set of
ingredient detections ON each hotdog bbox before and after a hand visit.
Items that newly appear on the hotdog after the hand leaves = committed items.

State machine per hotdog:
    CLEAN  -> (hand enters padded hotdog bbox)  -> ACTIVE
    ACTIVE -> (hand gone for MIN_CLEAN_FRAMES)  -> CLEAN + emit DiffEvents

Usage in main.py:
    diff_engine = HotdogDiffEngine()
    # inside per-frame loop, after hotdog_tracker.update():
    diff_events = diff_engine.update(
        hotdog_tracker=hotdog_tracker,
        detections=detections,
        current_time=current_time,
    )
    for evt in diff_events:
        # evt is a dict: {hotdog_tid, item_class, timestamp, hotdog_centroid}
        diff_action = Action(
            track_id=-1,
            zone_id="hotdog_diff",
            zone_name=evt["item_class"],
            action_type="place",
            timestamp=evt["timestamp"],
        )
        state_machine.on_action(diff_action)
        hotdog_tracker.force_commit_item(
            hand_working_pt=evt["hotdog_centroid"],
            item_class=evt["item_class"],
            now=evt["timestamp"],
            max_radius=400,
        )
"""

from __future__ import annotations

import logging
from dataclasses import dataclass, field
from typing import Dict, List, Optional, Set, Tuple

logger = logging.getLogger(__name__)


# ---- Constants ---------------------------------------------------------------

# Pad added around hotdog bbox when checking for hand proximity.
HAND_OVERLAP_PAD_PX: int = 80

# Number of consecutive frames without a hand before taking post-snapshot.
# At 30fps: 3 frames = 100ms debounce.
MIN_CLEAN_FRAMES: int = 3

# Minimum consecutive frames the hand must overlap hotdog to count as real interaction.
MIN_ACTIVE_FRAMES: int = 2

# Fraction of ITEM bbox area that must overlap hotdog bbox to count item as "on" hotdog.
ITEM_OVERLAP_RATIO: float = 0.3

# Item classes tracked by the diff engine.
TRACKED_ITEM_CLASSES: frozenset = frozenset({
    "onions",
    "diced_onions",
    "ketchup_sauce",
    "yellow_mustard_sauce",
    "relish",
    "tomato",
    "pickle_rounds",
    "pickle_spears",
    "sport_peppers",
    "chilli",
    "chili",
    "yellow_cheese",
    "swiss_cheese",
    "grated_yellow_cheese",
    "burger_bun",
    "sauerkraut",
})


# ---- Data structures ---------------------------------------------------------

@dataclass
class _DiffState:
    """Tracks diffing lifecycle for one hotdog track ID."""
    state: str = "CLEAN"                   # "CLEAN" | "ACTIVE"
    pre_snapshot: Set[str] = field(default_factory=set)
    hand_active_frames: int = 0
    clean_frames: int = 0
    hotdog_centroid: Tuple[float, float] = (0.0, 0.0)


# ---- Main class --------------------------------------------------------------

class HotdogDiffEngine:
    """
    Per-hotdog visual state diff engine.

    Call update() once per frame after HotdogTracker.update().
    Returns a list of DiffEvent dicts for newly committed items.
    """

    def __init__(
        self,
        hand_overlap_pad: int = HAND_OVERLAP_PAD_PX,
        min_clean_frames: int = MIN_CLEAN_FRAMES,
        min_active_frames: int = MIN_ACTIVE_FRAMES,
        item_overlap_ratio: float = ITEM_OVERLAP_RATIO,
    ) -> None:
        self.hand_overlap_pad = hand_overlap_pad
        self.min_clean_frames = min_clean_frames
        self.min_active_frames = min_active_frames
        self.item_overlap_ratio = item_overlap_ratio
        self._states: Dict[int, _DiffState] = {}

    def update(
        self,
        hotdog_tracker,
        detections: list,
        current_time: float,
    ) -> List[dict]:
        """
        Process one frame. Returns list of DiffEvent dicts:
          {
            "hotdog_tid":      int,
            "item_class":      str,
            "timestamp":       float,
            "hotdog_centroid": (float, float),
          }
        """
        events: List[dict] = []

        hand_dets = [d for d in detections if d.class_name == "hand"]
        item_dets = [d for d in detections if d.class_name in TRACKED_ITEM_CLASSES]

        active_tids = set(hotdog_tracker._records.keys())

        for tid, rec in hotdog_tracker._records.items():
            if rec.retired:
                continue

            if tid not in self._states:
                self._states[tid] = _DiffState()

            ds = self._states[tid]
            hotdog_bbox = rec.bbox
            hx1, hy1, hx2, hy2 = hotdog_bbox
            hcx = (hx1 + hx2) / 2.0
            hcy = (hy1 + hy2) / 2.0
            ds.hotdog_centroid = (hcx, hcy)

            hand_near = self._hand_near_hotdog(hand_dets, hotdog_bbox)
            current_on_hotdog = self._items_on_hotdog(item_dets, hotdog_bbox)

            if ds.state == "CLEAN":
                if hand_near:
                    ds.pre_snapshot = set(current_on_hotdog)
                    ds.state = "ACTIVE"
                    ds.hand_active_frames = 1
                    ds.clean_frames = 0
                    logger.debug(
                        "DiffEngine: hotdog tid=%d -> ACTIVE. pre_snapshot=%s",
                        tid, ds.pre_snapshot,
                    )
                else:
                    ds.pre_snapshot = set(current_on_hotdog)

            elif ds.state == "ACTIVE":
                if hand_near:
                    ds.hand_active_frames += 1
                    ds.clean_frames = 0
                else:
                    ds.clean_frames += 1
                    if ds.clean_frames >= self.min_clean_frames:
                        if ds.hand_active_frames >= self.min_active_frames:
                            post_snapshot = set(current_on_hotdog)
                            added = post_snapshot - ds.pre_snapshot

                            if added:
                                logger.info(
                                    "DiffEngine: hotdog tid=%d hand left. "
                                    "pre=%s post=%s added=%s",
                                    tid, ds.pre_snapshot, post_snapshot, added,
                                )
                                for item_class in added:
                                    events.append({
                                        "hotdog_tid":      tid,
                                        "item_class":      item_class,
                                        "timestamp":       current_time,
                                        "hotdog_centroid": ds.hotdog_centroid,
                                    })
                            else:
                                logger.debug(
                                    "DiffEngine: hotdog tid=%d hand left, "
                                    "no new items. pre=%s post=%s",
                                    tid, ds.pre_snapshot, post_snapshot,
                                )

                        ds.state = "CLEAN"
                        ds.hand_active_frames = 0
                        ds.clean_frames = 0

        for tid in list(self._states.keys()):
            if tid not in active_tids:
                del self._states[tid]

        return events

    def reset(self) -> None:
        """Clear all state (call when video source changes)."""
        self._states.clear()

    def _hand_near_hotdog(self, hand_dets, hotdog_bbox):
        hx1, hy1, hx2, hy2 = hotdog_bbox
        pad = self.hand_overlap_pad
        phx1, phy1, phx2, phy2 = hx1-pad, hy1-pad, hx2+pad, hy2+pad
        for h in hand_dets:
            bx1, by1, bx2, by2 = h.bbox
            w = bx2 - bx1
            h_height = by2 - by1
            cx = (bx1 + bx2) / 2.0
            sx1 = int(cx - (w * 0.6) / 2.0)
            sx2 = int(cx + (w * 0.6) / 2.0)
            sy1 = int(by2 - h_height * 0.6)
            sy2 = by2
            if sx2 >= phx1 and sx1 <= phx2 and sy2 >= phy1 and sy1 <= phy2:
                return True
        return False

    def _items_on_hotdog(self, item_dets, hotdog_bbox):
        hx1, hy1, hx2, hy2 = hotdog_bbox
        on_hotdog: Set[str] = set()
        for det in item_dets:
            ix1, iy1, ix2, iy2 = det.bbox
            inter_x1 = max(ix1, hx1)
            inter_y1 = max(iy1, hy1)
            inter_x2 = min(ix2, hx2)
            inter_y2 = min(iy2, hy2)
            iw = max(0, inter_x2 - inter_x1)
            ih = max(0, inter_y2 - inter_y1)
            inter_area = iw * ih
            item_area = max(1, (ix2 - ix1) * (iy2 - iy1))
            if (inter_area / item_area) >= self.item_overlap_ratio:
                on_hotdog.add(det.class_name)
        return on_hotdog

8. HOW THE TWO SYSTEMS WORK TOGETHER
================================================================================

After integration, two parallel systems run:

  System A -- Temporal/Dwell (EXISTING, unchanged)
    Watches:  hand in source bin zone
    Triggers: bin dwell >= threshold -> pending pick -> assembly -> place action
    Best for: Items not visible on the hotdog post-application

  System B -- Visual State Diff (NEW)
    Watches:  ingredient detections ON hotdog bbox before/after hand visit
    Triggers: item appears in post-snapshot but NOT in pre-snapshot -> commit
    Best for: Items YOLO can detect on the hotdog after application

DEDUPLICATION:
  Both systems can fire for the same item. The existing _committed_items set
  in HotdogRecord prevents double-counting: once a dry item is committed to
  a hotdog, further commits of the same class are ignored. Sauces use
  SAUCE_MAX_COMMITS = 2 which also handles this.

STRATEGY:
  After auditing which classes YOLO detects on the hotdog:
  - Classes YOLO reliably detects on hotdog -> use System B as primary
  - Classes YOLO cannot detect on hotdog   -> keep System A (dwell)


================================================================================
9. EDGE CASES AND HOW TO HANDLE THEM
================================================================================

EDGE CASE 1: YOLO false-positive in pre-snapshot
  Problem:  YOLO briefly detects "onions" on hotdog due to nearby tray.
            Pre-snapshot = {onions}. After real application, post = {onions}.
            Delta = empty. Real add not counted.
  Fix:      Require item to be detected in >= 3 consecutive CLEAN frames before
            including in pre-snapshot. Filters intermittent false positives.

EDGE CASE 2: Hand occludes hotdog entirely
  Problem:  Post-snapshot may have partial visibility.
  Fix:      Wait for MIN_CLEAN_FRAMES (3 frames, 100ms) after hand fully leaves.
            By then hotdog is visible again. Already handled by current code.

EDGE CASE 3: Two adjacent hotdogs, item bbox overlaps both
  Problem:  YOLO detects onion bbox overlapping both hotdog A and B.
            Both get onion counted.
  Fix:      Use item CENTROID ownership instead of area overlap:
            assign item to whichever hotdog bbox CONTAINS the item centroid.

EDGE CASE 4: Sauce applied gradually
  Problem:  Sauce may appear in pre-snapshot (bottle already near hotdog).
  Fix:      For sauce classes, track AREA DELTA not just presence/absence.
            Alternatively, keep sauces on System A (existing sauce logic).

EDGE CASE 5: Multiple hand visits to same hotdog
  Example:  Worker adds relish, leaves, then adds onions 30s later.
  Result:   After relish visit: diff fires {relish}. Pre-snapshot updated.
            After onion visit: diff fires {onions}. Correct.

EDGE CASE 6: Detection jitter near confidence threshold
  Problem:  Item detected with conf 0.48/0.52 alternating -> unstable snapshot.
  Fix:      Majority vote over last N clean frames: only include class if
            seen in >= K/N frames (e.g. 3 of 5). Similarly for post-snapshot.
